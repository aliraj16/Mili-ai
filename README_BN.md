# Mili AI — Premium UI Starter

এটি একটি Android/Kotlin + Jetpack Compose প্রিমিয়াম-থিম স্টার্টার প্রজেক্ট। এটি তোমার আগের `LiaAI_Mili_Full_Features` প্রজেক্টের ZIP নয় এবং বর্তমান প্রজেক্টের ফাইল না দেখে সেটি নিরাপদে পরিবর্তন করা সম্ভব নয়।

## ডিজাইন
- Premium dark navy / violet gradient
- Home dashboard, chat preview, Voice Studio profile controls, Orb settings, settings
- Bengali UI labels, Material 3 Compose components
- Android 10 (API 29) লক্ষ্য করে সাধারণ UI আর্কিটেকচার

## Build
1. Android Studio-তে প্রজেক্টটি খুলুন (Compose ও Gradle dependencies ডাউনলোড করতে ইন্টারনেট লাগবে)।
2. Android Gradle Plugin/Gradle version আপনার ইনস্টল করা Android Studio-র সঙ্গে সামঞ্জস্যপূর্ণ করুন।
3. Build > Make Project চালান।

এই ZIP-এ বাস্তব AI API, সম্পূর্ণ floating overlay service, WhatsApp/Messenger automation, বা সব permission flow যুক্ত করা নেই। এগুলো আলাদা করে পরীক্ষা ও নিরাপদে সংযুক্ত করতে হবে। AI API key কখনো source code-এ hardcode করবেন না।
